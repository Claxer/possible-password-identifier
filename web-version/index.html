A learning project.

A small educational toolkit for understanding character sets, combinatorics, and text analysis.

i/
01 / GENERATION

Character combinations

Choose a character set and length range to generate ordered strings. Results are capped to limit browser memory usage.

02 / MATHEMATICS

Combination statistics

When repetition is allowed, the number of strings of length n from an alphabet of k characters is kⁿ.

03 / ANALYSIS

Character inspection

Review length, character classes, and a rough theoretical entropy estimate based on the observed character categories.

04 / PRIVACY

Local processing

The application has no server connection and does not send your inputs anywhere. Generated files are saved only when you export them.

Important limitation

This tool does not discover actual account passwords, verify credentials, or connect to login services. Entropy estimates are theoretical and may overstate the unpredictability of human-chosen text.
